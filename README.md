# 价格监督员线索保护

保护企业价格监督员身份并持续追踪跨地区线索的受理和处置。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括企业价格监督员、线索受理人员、价格执法承办人员、跨地区协查单位、内部监察人员。

资料所依据的领域事实如下：

- 监管部门研究制定价格监督员制度规定
- 企业将承担价格合规主体责任
- 恶意低价和无序竞争属于治理重点
- 隐蔽返利是推动恶意低价的常见手段
- 监督员身份仅在必要范围内经审批揭示
- 查阅、转交、退回全程留痕并逐条注明理由
- 监督员离职不影响线索效力和匿名通道使用

## 保密线索协作

共享资料围绕一条线索的连续记录展开：

- 线索记录：举报内容摘要、附件指纹、涉及主体、商品范围、紧急程度与当前状态
- 生命周期事件：受理、查阅、身份揭示、管辖移送、转交、退回、补证请求、补证接收、并案、撤回登记、回避改派、办结反馈，逐条注明理由并保持序号连续
- 身份保护：监督员以代号出现，真实身份仅在必要范围内经审批揭示，匿名通道凭一次性口令查看节点与回应
- 处理规则：重复举报并案、跨区域移送、监督员离职、材料撤回、利益冲突回避各有明确规则
- 监察要点：超期预警、越权访问告警、打击报复迹象监测、处置失真核验

承办人员仅获得最小必要信息；任何查阅、转交或退回都必须留下理由。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实、约束、线索记录、生命周期事件、身份保护、处理规则和监察要点。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
