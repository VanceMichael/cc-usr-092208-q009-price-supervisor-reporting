# 价格监督员线索保护

保护企业价格监督员身份并持续追踪跨地区线索的受理和处置。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括企业价格监督员、价格执法承办人员、跨地区协查单位、内部监察人员。

资料所依据的领域事实如下：

- 监管部门研究制定价格监督员制度规定
- 企业将承担价格合规主体责任
- 恶意低价和无序竞争属于治理重点
- 跨地区拆分的线索需要统一反馈，避免无人回应
- 匿名线索需要可补证的沟通渠道，避免长期占用执法资源

## 保密线索协作

共享资料围绕一条线索的连续记录展开：

- `clue_record` 登记举报内容、附件指纹、涉及主体、商品范围、紧急程度与当前状态。
- `events` 按序号连续记录受理、管辖移送、补证请求、查阅、转交、退回等节点，任何操作都留下理由；身份揭示必须另附必要范围与审批说明。
- `identity_policy` 规定默认匿名、身份揭示条件，以及承办人员可见的最小必要字段。
- `anonymous_channel` 规定监督员凭匿名令牌可见的节点与回应，以及对监督员隐藏的内容。
- `handling_rules` 覆盖重复举报、跨区域行为、监督员离职、材料撤回和利益冲突五类情形。
- `oversight` 说明监察人员发现超期、越权访问、打击报复迹象的方式，以及如何证明案件处置未因举报者身份而失真。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束，以及线索记录要素、事件连续性、操作理由、身份揭示规则、处理规则和监察能力。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
