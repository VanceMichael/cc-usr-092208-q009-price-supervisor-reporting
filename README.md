# 价格监督员线索保护

保护企业价格监督员身份并持续追踪跨地区线索的受理和处置。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括企业价格监督员、价格执法承办人员、跨地区协查单位、内部监察人员。

资料所依据的领域事实如下：

- 监管部门研究制定价格监督员制度规定
- 企业将承担价格合规主体责任
- 恶意低价和无序竞争属于治理重点

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
